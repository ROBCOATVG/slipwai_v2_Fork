# Slipwai 2

Slipwai creates and runs product repositories for coding agents. Say the name as "slipway".

This fork is slipwai 2 under construction. The tree was cleared on 2026-10-06 and is being brought back in v2
shape one module at a time: a keel, languages and extensions from a chandlery, fairways charted before any slice
sails, and captains under a harbourmaster on append-only logs. The plan, the vocabulary and the order of work are
in [docs/slipwai-2-plan.md](docs/slipwai-2-plan.md).

Until 2.0.0 is cut, nothing here maintains 1.x's working contract: there is no `migrate`, no catch-up note and no
changelog fragment. The fork merges back to [ROBCOATVG/slipwai](https://github.com/ROBCOATVG/slipwai) as v2 once,
when complete. The history behind this commit is upstream's at 1.5.2.dev0; the experiment it draws on is
`slipwai-cruise-2`.

Sources each module comes back from: upstream `main` at `e1a9e43`, or `slipwai-cruise-2` `main` at `c6f1e74`.
